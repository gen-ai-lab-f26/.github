# Generative AI Lab (TECH-UB 41 · Fall 2026)

**NYU Stern · Tuesdays 5:00–8:00 PM · KMC 2-90**
Instructor: Christian Grewell (`christian@nyu.edu`)

Build a working AI product for one real person, test it with real people, and demo it on December 8.

**[Final Project brief](https://www.icerynk.com/c/fa26-tech-ub-41-7w2-001/content/final-project-ai-product-and-demo)** · **[Icerynk course](https://www.icerynk.com/c/fa26-tech-ub-41-7w2-001/content)** · **[Project template](https://github.com/gen-ai-lab-f26/project-template)**

Icerynk holds the brief, the rubric and your submission. GitHub holds your code, your `INTENT.md` and `TEST_LOG.md`, and your public Product Page.

## Start here, before Tuesday, November 24

1. **Get a GitHub account.** No account yet? Make a free one at [github.com/signup](https://github.com/signup).
2. **Join this organization.** Put your GitHub link in [Final Project: GitHub username and team](https://www.icerynk.com/c/fa26-tech-ub-41-7w2-001/content/final-project-github-username-and-team) on Icerynk, then accept the invitation GitHub emails you. Accept it before you make your repo.
3. **One teammate makes the team repo.** Open [`project-template`](https://github.com/gen-ai-lab-f26/project-template) and choose **Use this template → Create a new repository**. Set the owner to `gen-ai-lab-f26`, give it a short name for your project (for example `dues-checker`), and choose **Public**.
4. **Add your teammates.** In your repo: **Settings → Collaborators and teams → Add people**, with the **Write** role.
5. **Turn on your Product Page.** **Settings → Pages → Deploy from a branch → main → /docs → Save.** About a minute later it is live at `https://gen-ai-lab-f26.github.io/<your-repo>/`.

Working solo? Do steps 3 and 5 yourself and skip step 4.

## Keep secrets out of GitHub

Your repo is public. Put API keys in a local `.env` file; the template already keeps `.env` out of Git. Never put a key in code, a screenshot or a commit. If a key leaks, revoke it with the service that issued it and make a new one.
